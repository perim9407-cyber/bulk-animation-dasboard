02 / Roblox Publisher

Mengunggah satu file per permintaan melalui Roblox Open Cloud.

Gunakan hanya audio yang kamu miliki atau berhak gunakan. URL YouTube memerlukan yt-dlp dan FFmpeg di server.

Saya memiliki hak atau izin yang diperlukan untuk mengunggah dan menggunakan audio ini, serta memahami Roblox tetap melakukan pemeriksaan dan moderasi.
Maksimal 20 MB dan 7 menit menurut dokumentasi Roblox. Batas akun juga berlaku.

API key hanya berada di server Railway. Aset belum tentu langsung dapat digunakan; pengaturan izin experience mungkin diperlukan di Creator Dashboard.
